## 1. Why this task exists

`reminders` joins `kPumpableVariants`, and the empty state **explains where reminders come
from** — a screen that says *no reminders* to a shepherd who does not know the app creates them from
lambings and treatments has taught them nothing.

07 §2.2 is explicit that this is not decoration: spec §5 bans onboarding, so **the empty states are the
teaching surface** (decision #71). This is the only place the app ever explains where reminders come from.

### 5.3 The details that are easy to get wrong

- **Adding the row costs four test files, not one.** 12 §6.2 and §7.4: the same table drives the overflow
  matrix (**+3 devices × 3 scales × 2 bold = 18 cells**), `semantics_gate_test.dart` and
  `tap_target_test.dart` (**+3 devices × 2 scales = 6 runs each**), and `contrast_test.dart`
  (**+3 palettes on `Device.small` at scale 1.0**). So this one line requires the Reminders screen to pass
  the geometric gate (every `ShedTapTarget` ≥ 60 pt on both axes *and* exposing `SemanticsAction.tap`), the
  semantics gate (every node labelled; at least one `headingLevel > 0`) and the contrast gate (pixel
  sampling under night, amber **and** deep red) — in this commit. Run all four before you commit, not just
  the matrix.
- **The count stays derived.** `expect(kPumpableVariants.length, 14)` belongs to **N33-T01**
  (`'the matrix covers every route, and the count is 14'`). Do not add a remembered number here; the
  arithmetic follows the variant list (R58), and decision #114's 216 is already superseded once.
- **Pumping the empty state and calling it populated is `00-PLAN-CRITIQUE` S10, exactly.**
  `flock_400_3seasons.json` was generated one epic before reminder rows had a writer; N24-T08 regenerated
  it. Assert the fixture's reminder count is > 0 **before** asserting anything about layout, or this task
  silently proves nothing for the rest of the project's life.
- **Fixtures load through `RestoreService`, never a bespoke loader.** `restoreFixture(db, 'flock_400_3seasons.json')`
  (12 §5.2, decision #74) — which makes the fixture loader a continuous test of the one code path where a
  bug loses five seasons.
- **The most likely failing cell is `reminders · small · scale 2.0 · bold true`, and the thing that fails
  is T02's fixed-height box.** 07 §17.3 rule 2 requires the reconcile line to be the same height in all
  three states so the list below never shifts — and the naive way to do that is a constant height, which
  overflows the moment the text scaler doubles. The height must be computed from the **scaled** text of
  the longest of the three messages. Reproduce one cell with
  `--plain-name 'reminders · small · scale 2.0 · bold true'`.
- **Overflow is necessary and not sufficient** (12 §6.2): *"a layout can avoid overflowing by pushing the
  Save button below the fold."* Reminders is not one of the three variants carrying the extra reachability
  assertion — but the honest line's "Turn on alerts" button is the one control on this screen a shepherd
  must reach, so assert it is on screen at `Device.small` × 2.0 anyway.
- **Never a spinner, never an illustration, never a tour** (07 §2.2). `CircularProgressIndicator` under
  `lib/features/**` is a gate row. The empty state is one line and one control.
- **The whole-screen empty state and the per-bucket empty lines are different things and both must exist.**
  Zero open reminders → `ShedEmptyState` with the two-source sentence. Some buckets empty → the bucket
  keeps its `headingLevel: 2` heading and shows one 18 pt line (T01). A screen that collapses the second
  case into the first loses the most reassuring line on the screen at 03:00.
- **Filtered-empty is impossible on this screen** (07 §11.3): the buckets are a partition, not a filter.
  There is no "Clear filters" action and no third empty string.
- **The empty state names both sources because there is no onboarding.** Decision #71. Deleting "when you
  record a lambing or a treatment" to shorten the line deletes the only explanation the product has.
- **`pumpApp` gives the screen a notch and a home indicator** (`EdgeInsets.only(top: 47, bottom: 34)`) on
  purpose — a zero-padding harness hides the class of bug where a bottom-anchored 60 pt target sits under
  the home bar. The `DONE` / `MUTE` word buttons live in the thumb band; that is precisely the band at
  risk.
- **`pumpAndSettle()` with no timeout is only safe because indefinite animations are banned.** T04's strike
  is 180 ms and finite. If anything on this screen ever loops, every one of these 18 cells hangs for ten
  minutes and then fails opaquely.

## 6. Constraints that bind this task
