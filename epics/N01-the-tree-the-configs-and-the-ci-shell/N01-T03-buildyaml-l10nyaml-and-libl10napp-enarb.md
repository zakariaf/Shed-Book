## 1. Why this task exists

Drift as the **only** generator in `build.yaml`, with no banned build option; `l10n.yaml`
with `en` only and the generated output committed; and **`lib/l10n/app_en.arb` with its first string
and its `description`**. The old plan created `l10n.yaml` and never created the ARB — the first
user-facing string in the Quick Entry epic would have had nothing to land in.

Both files freeze something. `build.yaml`'s absent `store_date_time_values_as_text` is
**irreversible after the first schema snapshot** (decision #29, N07) because it forces one storage
representation onto instants and civil dates, which are different kinds. And `00-README` §9 lists the
ARB as one of exactly two things that *"run in parallel from day one, not at the end"* — every string
goes through `app_en.arb` from the first one, because the cost is ten seconds per string now and a
full-app sweep later. N33 only **verifies**; there is no epic that adds descriptions afterwards.

### 5.2 The three files

`build.yaml`, verbatim from 03 §1.2:

```yaml
# build.yaml — NOT build.yml. A drift discussion exists solely because
# someone lost a day to that typo and FTS5 silently stayed disabled.
targets:
  $default:
    builders:
      drift_dev:
        options:
          sql:
            dialect: sqlite
            options:
              modules:
                - fts5
          # Result sets get value equality so `.distinct()` in the repository
          # actually suppresses duplicate stream emissions (decision #12).
          override_hash_and_equals_in_result_sets: true
          databases:
            shed_book: lib/core/db/database.dart
          schema_dir: drift_schemas/
          test_dir: test/drift/
```

`l10n.yaml`, verbatim from 10 §8.2:

```yaml
# l10n.yaml — repo root (CONVENTIONS §1). Ships en only.
arb-dir: lib/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
output-class: AppLocalizations
# Every message must carry a description. Ten seconds each; it is where the
# safety rationale for a string lives (§8.4).
required-resource-attributes: true
# AppLocalizations.of(context) with no `!`.
nullable-getter: false
# Named parameters, so a three-placeholder message is readable at the call site.
use-named-parameters: true
```

`lib/l10n/app_en.arb` — the first string. It is 10 §8.4's `withdrawalSource`, and it is the right
one to be first because it is the message whose *wording* is a safety requirement rather than a
style choice, so the `description` mechanism is proving itself from the first key:

```json
{
  "@@locale": "en",

  "withdrawalSource": "Withdrawal period: {days} days, as entered by you",
  "@withdrawalSource": {
    "description": "Spec 12.1 provenance. The wording 'as entered by you' is a SAFETY REQUIREMENT, not a style choice. Do not shorten it. Never show a withdrawal figure without it.",
    "placeholders": {
      "days": { "type": "int" }
    }
  }
}
```

The call site it generates, which is what `nullable-getter: false` and `use-named-parameters: true`
buy — recorded here so the shape is settled before N20 needs it:

```dart
AppLocalizations.of(context).withdrawalSource(days: 7)
```

### 5.3 What is easy to get wrong here

- **`synthetic-package` is dead. Do not write it in either polarity.** Its own help text on Flutter
  3.44 reads *"DEPRECATED. This flag cannot be enabled and should be removed"*, and 10 §10 lists it
  as anti-pattern 31. Any tutorial that sets it — and any earlier draft of this task file that told
  you to set it `false` — predates 3.32. The generated output is committed because `arb-dir` is
  inside `lib/` and `00-README` §7.1 says commit it, not because a flag was flipped.
- **`build.yaml`, never `build.yml`.** 03 §1.2 carries that comment because somebody lost a day to
  the typo and FTS5 silently stayed disabled — `build_runner` does not warn about a config file it
  never found.
- **`store_date_time_values_as_text` must be absent, and this is the file where it would be set.**
  Setting it is irreversible after the first snapshot and it forces one representation onto instants
  (`INTEGER` UTC epoch millis) and civil dates (`TEXT 'YYYY-MM-DD'`), which decision #2 keeps
  separate. N03's gate greps `build.yaml` for the key; the mistake becomes permanent at N07.
- **`schema_dir` and `test_dir` must name directories that exist.** N01-T01 created
  `drift_schemas/` and `test/drift/generated/`. Point them anywhere else and `make-migrations` at
  N08 writes the snapshots into a path nothing commits — and losing a schema snapshot is the one
  loss `00-README` §7.1 calls unrecoverable.
- **`build.yaml` names drift; it does not by itself make drift the only generator.** That is
  decision #16 plus the dependency set, held by G2's `[dev_dependencies]` allowlist in N03. This
  file's job is to configure the one builder that exists, not to disable ones that are not there.
- **`required-resource-attributes: true` makes a missing `description` a generation *failure*.**
  That is the whole mechanism, and it is why the safety rationale for a string can live somewhere a
  future contributor will actually read it. Do not soften it to get a build green.
- **Message ids are `lowerCamel` concept names, never the English text.** `penReadyThreshold`, not
  `readyDashYourTwentyFourHourThreshold`.
- **No domain noun ever appears literally in a message.** The nouns are the seven `AnimalClass`
  labels — ewe, gimmer, theave, tup, wether, lamb — and they arrive as a `{term}` placeholder fed by
  `terminologyProvider` (10 §8.5). `"Turn out ewe {tag}?"` is the failure mode that survives code
  review; `"Turn out {term} {tag}?"` is the fix.
- **Plural placeholders are `singularTerm` and `pluralTerm`, never `singular` and `plural`.**
  `plural` is an ICU keyword; a placeholder that shadows it parses today and stops parsing on the
  next gen-l10n release. And never derive a plural by appending "s" — the user typed one word and
  guessing the other is a §12.4 violation.
- **Not everything user-facing is an ARB message, and the exception list is closed** (10 §8.4 rule
  5): the three `Disclaimers` constants, the six `ShedFailure.userMessage` strings and
  `RecordedTime.provenanceLabel` are `const` Dart, because a translator can soften or drop an ARB
  string and the app has no mechanism to notice. `NightErrorPanel` is hard-coded English by
  construction — it renders outside `Localizations` and a lookup there is a crash inside the crash
  handler. Adding a seventh exception is a review conversation, not an edit.
- **`intl: any`, exactly.** `flutter_localizations` on 3.44 pins `intl: 0.20.2` **exactly**, so
  `^0.20.3` does not resolve. Re-check after every Flutter upgrade.
- **The generated file will be silently regenerated under you.** With `flutter: generate: true`,
  `flutter run` and `flutter build` re-run gen-l10n. Always finish with
  `git diff --exit-code -- lib/l10n/` before committing; N08's `codegen` job makes that a gate.
- **Tell N03 about the generated file.** `lib/l10n/app_localizations*.dart` matches neither
  `*.g.dart` nor `*.drift.dart`, so it needs an explicit entry in the gate's skip list — 10 §10
  amendment (b), already named in N03-T01. Without it every content rule fires on the ARB twice.
- **The `supportedLocales` ordering trap is real but it is not this file's.** `Locale('en')` must be
  **first** in the list `lib/app.dart` passes, or every English speaker on earth gets British date
  formats. That lands in N11; this task only makes one `app_en.arb` the thing it resolves to.

## 6. Constraints that bind this task

- **Accessibility and the ARB, authored here** — every string in `app_en.arb` with a `description`, every element a `semanticLabel` and a `<screen>.<element>` key, every heading a `headingLevel:`. There is no later sweep that adds them; N33 only verifies.
- **§12.1, at the level of *copy*** — `withdrawalSource` carries the words *as entered by you*. That
  wording is the provenance half of the never-default rule and is not shortened, reworded or
  reflowed at any call site.
- **Offline** — no network path may be added. G2 (the dependency allowlist) and G3 (the import scan) stay green, and the permission set never changes without G0's recorded evidence. gen-l10n generates source at build time and `flutter_localizations` bundles its CLDR data as generated Dart, so nothing here opens a socket.
- **Vocabulary** — one word per concept (`CLAUDE.md`). The banned words are banned in the commit message too: no `draft`, no `save()`, no `sync`, no `Error` as a failure name.
